# Part 1

Cada subpasta contém uma aplicação React independente:

- `courseinfo`: exercícios 1.1–1.5, informações do curso e cálculo do total de exercícios.
- `unicafe`: exercícios 1.6–1.11, coleta de feedback e estatísticas.
- `anecdotes`: exercícios 1.12–1.14, seleção aleatória, votos e anedota mais votada.

Para executar uma aplicação, entre na pasta correspondente e rode:

```sh
npm install
npm run dev
```
